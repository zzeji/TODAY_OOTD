오늘 뭐 입지 - 아이폰 홈 화면 앱 설치 방법

1. GitHub(github.com) 가입 후 오른쪽 위 + → New repository
   - 이름: closet (원하는 이름), Public 선택 → Create repository
2. "uploading an existing file" 클릭 → 이 폴더 안의 파일과 icons 폴더를 통째로 끌어다 놓기 → Commit changes
3. 저장소의 Settings → Pages → Branch를 main / (root)로 선택 → Save
4. 1~2분 뒤 표시되는 주소(https://아이디.github.io/closet/)를 아이폰 Safari로 열기
5. Safari 하단 공유 버튼 → "홈 화면에 추가" → 추가

업데이트할 때
- index.html을 새 파일로 다시 올리고, sw.js 안의 VERSION 값을 v1 → v2처럼 올려서 함께 올리기
- 앱을 완전히 닫았다가 다시 열면 새 버전이 적용됨

기존 데이터 옮기기
- PC에서 "백업 파일 저장" → 파일을 아이폰으로 보내기(에어드롭, 카카오톡 나에게 보내기 등)
- 아이폰 앱에서 "백업 불러오기" → 파일 선택
